# Estructuras de datos (JS)

## Conceptos

### Arreglos
Un arreglo es una estructura lineal que almacena una colección ordenada de elementos, accesibles por un índice numérico.

### Objetos
Un objeto es una estructura que agrupa información en pares clave–valor, donde las claves identifican propiedades y sus valores asociados.

### Módulos
Un módulo es una unidad de código que encapsula funcionalidades y expone una interfaz pública mediante exportaciones, permitiendo reutilización y separación de responsabilidades.
